# Signoff Studio — public support

Public bug reports and community discussions for [Signoff Studio](https://qasignoff.com).

- **Issues** — bug reports from the desktop app and VS Code extension, plus reports filed here manually
- **Discussions** — questions, ideas, and general feedback

When reporting from the app, use **Help → Report a problem** or the **Report a bug** button in the bottom bar.

For defects with screenshots or diagnostic logs, use **Copy report** or **Open mail app** in the same dialog and email `fixit@qasignoff.com`.
